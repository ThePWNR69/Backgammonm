# Backgammon Legacy v1.2 — brand system

## Product name

**Backgammon Legacy**

Primary menu wordmark treatment:

**BACKGAMMON**  
**L E G A C Y**

## Core visual identity

- Crown / dice / checker emblem from the approved v1.1 design.
- Deep emerald foundation.
- Warm gold / champagne accents.
- Premium walnut and dark leather materials.
- Serif display typography for major headings, restrained sans-serif for utility copy.

## Android surfaces

The app label is now `Backgammon Legacy` and is used by Android launcher/app metadata.
Adaptive, round and monochrome launcher icon support from v1.1 is retained.
The splash experience continues to use the approved emblem and emerald brand colour.


## Screen-title rule

The full **Backgammon Legacy** wordmark is reserved for the launcher/app identity, splash/branding moments and main menu. Functional screens use concise titles such as **STORE**, **CUSTOMISE**, and **PROFILE** so the brand is not repeated unnecessarily.
