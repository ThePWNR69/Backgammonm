# Backgammon Legacy v1.8.0 — Variants + Progression Economy

- Adds playable Backgammon / Sheish Beish, Mahbouseh and Tawla 31 setup choices.
- Mahbouseh uses pinning instead of standard hits and starts all 15 checkers together.
- Tawla 31 is a no-hit blocking race, starts all 15 checkers together, and applies the first-runner opening restriction.
- Adds Hints On/Off to Match Setup. Hint control keeps its locked HUD slot but is hidden when disabled.
- Adds persistent XP and Gold using SharedPreferences.
- Both wins and losses earn progression.
- Rewards use a common normalized calculator so variants start with equal economy multipliers.
- Easy/Normal/Hard AI apply 0.80x / 1.00x / 1.30x reward tuning.
- Hint use reduces bonus rewards while protecting a participation floor.
- Adds end-of-game reward summary.
- Keeps v1.7.0 gameplay HUD and v1.6.5 BoardMap/checker geometry unchanged.
- GitHub build output is now named Backgammon-Legacy-v1.8.0.apk.
