# Backgammon Legacy v1.6.0 — Gameplay Visual Rebuild

This release deliberately focuses only on the live match screen. No Store, Customise, Profile or setup-screen redesign work was added in this version.

## Gameplay screen

- Rebuilt the top HUD to more closely match the approved luxury gameplay reference.
- Reduced player checker icons and round-score badges so every element remains fully inside the nameplate.
- Tightened player-name, divider and round-score spacing.
- Added restrained gold ornaments around the centre status message.
- Removed excess vertical UI space so the physical board is substantially larger on wide 20:9 phones.
- Increased the board region from 80% to 85.8% of the vertical layout budget.
- Rebalanced the bottom Undo / main action / Menu controls to match the compact reference proportions.
- Removed default Button minimum-height/padding behaviour that could make controls overflow the intended footer band.

## Material polish

- Refined the walnut board colour treatment with slightly richer warmth, contrast and detail.
- Increased the cached board contact shadow so the case sits more naturally on the emerald tabletop.
- Refined the dark brown / gold player panels, emerald status panel and action-button borders.
- Refined round score badges with a smaller inset gold-ring treatment.

## Preserved from v1.5.0

- Triangle-edge midpoint checker alignment from v1.4.4.
- One permanent invisible BoardMap.
- Fixed checker sizing across cosmetic sets.
- AI, opening roll, Undo, turn review and End Turn behaviour.
- Round score tracking in player nameplates.
- Main menu, setup screens, Store, Customise and Profile remain functionally unchanged in this focused release.
