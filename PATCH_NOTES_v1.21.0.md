# v1.21.0 — Polished Gameplay Visual Pass

This release uses the approved luxury gameplay references as the finish target without changing gameplay rules.

- Rebuilt Classic Burgundy board artwork against the existing 2048×977 BoardMap geometry.
- Added richer walnut rails, layered bevels, dark leather field, burgundy side trays and brass trim/hinges.
- Rebuilt Player 1 / Player 2 HUD plaque backgrounds with clean full edges and smaller integrated score bays.
- Rebuilt the centre status plaque with a dimensional gold finish.
- Rebuilt menu/settings button artwork with complete rounded edges and matching gold trim.
- Rebuilt the bottom control deck, dice wells and normal button surfaces.
- Rebuilt pressed/disabled button overlays for the tactile button system.
- Rebuilt Ivory/Walnut checker sprites at 512×512 with a 448px visible disc and no baked exterior shadow; runtime supplies the shadow so scaling stays clean.
- Increased checker visible-bounds alpha threshold so faint antialiasing/shadow pixels do not shrink the displayed checker.
- Refined HUD identity icon rings and made identity icons explicitly visible.
- Reduced AI-name font size and tightened plaque internals to prevent clipping.
- Rebuilt dice face artwork to match the polished ivory set.
- Backgammon, Mahbouseh, Tawla 31, AI, hints, XP/Gold and Match Setup logic are unchanged.
